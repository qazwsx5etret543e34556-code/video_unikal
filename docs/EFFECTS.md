# Video Uniqueizer Pro - Все 24 Эффекта

## Цветокоррекция (Color Correction)

### 1. Brightness (Яркость)
- **Диапазон**: -255..255
- **FFmpeg фильтр**: `eq=brightness=X/255`
- **Описание**: Изменяет яркость видео. 0 = оригинал.
- **Рекомендация для уникализации**: -15..15

### 2. Contrast (Контрастность)
- **Диапазон**: -100..100
- **FFmpeg фильтр**: `eq=contrast=1+X/100`
- **Описание**: Изменяет контраст. 0 = оригинал.
- **Рекомендация**: -10..10

### 3. Sharpness (Чёткость)
- **Диапазон**: -100..100
- **FFmpeg фильтр**: `unsharp=5:5:X/50:5:5:0`
- **Описание**: Повышение резкости или размытие.
- **Рекомендация**: -5..5

### 4. Saturation (Насыщенность)
- **Диапазон**: 0..200 (100 = оригинал)
- **FFmpeg фильтр**: `eq=saturation=X/100`
- **Описание**: Насыщенность цвета. 0 = ч/б, 200 = очень ярко.
- **Рекомендация**: 90..110

### 5. Hue (Оттенок)
- **Диапазон**: -180..180
- **FFmpeg фильтр**: `hue=h=X`
- **Описание**: Сдвиг цветового тона в градусах.
- **Рекомендация**: -5..5

### 6. Color Balance (Баланс цвета)
- **Диапазон**: 3 слайдера (shadows, midtones, highlights)
- **FFmpeg фильтр**: `colorbalance=rs/gs/bs/rm/gm/bm/rh/gh/bh`
- **Описание**: Баланс цвета для теней, средних тонов и светов.
- **Рекомендация**: -0.1..0.1 для каждого канала

## FX Эффекты

### 7. Speed (Скорость)
- **Диапазон**: 50..200%
- **FFmpeg фильтры**: `setpts=100/X*PTS`, `atempo=100/X`
- **Описание**: Ускорение или замедление видео.
- **Примечание**: Требуется коррекция аудио (atempo поддерживает 0.5x-2.0x)

### 8. Resolution (Разрешение)
- **Диапазон**: 50..200%
- **FFmpeg фильтр**: `scale=iw*X/100:ih*X/100`
- **Описание**: Изменение размера кадра.
- **Рекомендация**: 95..105%

### 9. Zoom (Увеличение)
- **Диапазон**: 50..200%
- **FFmpeg фильтры**: `crop`, `scale`
- **Описание**: Цифровое увеличение с кропом.
- **Рекомендация**: 100..110%

### 10. Rotate (Поворот)
- **Диапазон**: -360..360 градусов
- **FFmpeg фильтр**: `rotate=X*PI/180`
- **Описание**: Поворот видео на угол.
- **Рекомендация**: -2..2 градуса для незаметной уникализации

### 11. Flip Horizontal (Отражение горизонтально)
- **Тип**: Boolean
- **FFmpeg фильтр**: `hflip`
- **Описание**: Зеркальное отражение по горизонтали.

### 12. Flip Vertical (Отражение вертикально)
- **Тип**: Boolean
- **FFmpeg фильтр**: `vflip`
- **Описание**: Зеркальное отражение по вертикали.

### 13. Noise (Шум)
- **Диапазон**: 0..100
- **FFmpeg фильтр**: `noise=alls=X:allf=t`
- **Описание**: Добавление цифрового шума.
- **Рекомендация**: 1..5

### 14. Blur (Размытие)
- **Диапазон**: 0..20
- **FFmpeg фильтр**: `boxblur=X`
- **Описание**: Размытие всего кадра.
- **Рекомендация**: 0..1 (очень слегка)

## Оверлеи (Overlays)

### 15. Sticker (Стикер)
- **Тип**: FilePicker (PNG с прозрачностью)
- **FFmpeg фильтр**: `overlay=x,y`
- **Описание**: PNG изображение с рандомной позицией.
- **Параметры**: Позиция X/Y рандомизируется в пределах кадра.

### 16. Background Audio (Фоновое аудио)
- **Тип**: FilePicker (MP3/WAV)
- **FFmpeg фильтр**: `amix`, `volume`
- **Описание**: Наложение фоновой музыки.
- **Громкость**: 0.1..0.9 (микширование с оригиналом)

### 17. Start Image (Картинка в начале)
- **Тип**: FilePicker
- **Длительность**: 0.2 секунды
- **FFmpeg фильтр**: `concat`
- **Описание**: Статичное изображение перед основным видео.

### 18. Bait Video (Байт-видео в конце)
- **Тип**: FilePicker (MP4)
- **FFmpeg фильтр**: `concat`
- **Описание**: Дополнительное видео после основного.

### 19. Transparent Square (Прозрачный квадрат)
- **Тип**: Boolean
- **Прозрачность**: Alpha 5%
- **FFmpeg фильтр**: `color`, `overlay`
- **Описание**: Почти невидимый оверлей для уникализации хэша.

### 20. Background Replace (Подмена фона)
- **Варианты**: "black" или "video"
- **FFmpeg фильтр**: `colorkey`, `overlay`
- **Описание**: Замена фона на чёрный или другое видео.

## Множители (Multipliers)

### 21. Multiplier (Множитель копий)
- **Диапазон**: 1..100
- **Описание**: Создаёт N уникальных копий с разными параметрами.
- **Примечание**: Каждая копия получает рандомизированные параметры всех эффектов.

### 22. Metadata Clean (Очистка метаданных)
- **Тип**: Boolean
- **FFmpeg опции**: `-map_metadata -1`, `-write_tmcd 0`
- **Описание**: Удаляет все метаданные (кодек, дата съёмки, GPS и т.д.)

## Аудио Эффекты

### 23. Audio Pitch Shift (Сдвиг тона)
- **Диапазон**: -5..5 полутонов
- **FFmpeg фильтр**: `asetrate=44100*2^(X/12),aresample=44100`
- **Описание**: Изменение высоты звука без изменения скорости.
- **Рекомендация**: -2..2 полутона

### 24. Audio Volume (Громкость аудио)
- **Диапазон**: 50..200%
- **FFmpeg фильтр**: `volume=X/100`
- **Описание**: Изменение громкости аудио дорожки.
- **Рекомендация**: 95..105%

## Применение Эффектов

### Рандомизация
Для каждого файла в очереди параметры эффектов рандомизируются в указанном диапазоне. Это обеспечивает уникальность каждого выходного файла даже при одинаковых настройках.

### Пример команды FFmpeg
```bash
ffmpeg -i input.mp4 \
  -vf "eq=brightness=0.05:contrast=1.02:saturation=1.03,\
       unsharp=5:5:0.1:5:5:0,\
       hue=h=2,\
       scale=iw*1.02:ih*1.02,\
       noise=alls=2:allf=t" \
  -af "asetrate=44100*2^(1/12),aresample=44100,volume=1.05" \
  -c:v libx264 -preset medium -crf 22 \
  -c:a aac -b:a 192k \
  output.mp4
```

### Safe Profile (Fallback)
Если пользовательские параметры приводят к ошибке кодирования, автоматически применяется безопасный профиль:
- Только re-encode с libx264 + aac
- Без сложных фильтров
- CRF 23, preset fast
- Сохранение результата с логированием fallback
